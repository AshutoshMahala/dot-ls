# Retired development material

`tools/` contains source-specific profiling scripts and Zig harnesses used for
earlier experiments. Several locate source fragments by exact text replacement.
They do not match the current source and are not supported development commands.
They are preserved to explain historical measurements, not to run against the
current project. Their original source paths are intentionally unchanged.

`layout-migration.json` records the documentation/tool moves and original file
hashes. Raw measurement contents were preserved. Historical Markdown links were
updated for their new locations. A temporary pre-cleanup copy was also made at
the location recorded in that manifest; it is not a project dependency.
